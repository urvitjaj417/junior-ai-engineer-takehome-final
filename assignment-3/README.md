# Assignment 3 — Resumable Agent with Basic Self-Check

The agent processes five short files in order. It writes one summary per file, persists after each item through LangGraph's `SqliteSaver`, and can be invoked again with the same `thread_id`. On resume it starts its scan from the beginning, logs items 1–3 as already completed, and processes only items 4 and 5. The stop-resume demonstration therefore makes the skip behavior visible in the transcript instead of relying on an implicit index.

After all items finish, the check node compares every summary to its source. The demo deliberately corrupts item 4 on the first pass, so the check reports a specific mismatch instead of silently passing. The state records `completed`, `results`, `next_index`, `paused`, `checked`, and `issues`; it is ordinary, readable LangGraph state stored by the built-in SQLite checkpointer.

```bash
python resumable_agent.py --scenario stop-resume
python resumable_agent.py --scenario clean
python resumable_agent.py --scenario clean --live  # requires OPENAI_API_KEY
```

To run both Assignment 3 demonstrations together:

```bash
python demo.py
python demo.py --live
```

The transcript reports the total external LLM calls. Deterministic mode reports zero because summaries are generated by a local function. With `--live`, the model generates summaries and the state counts each call; a model failure falls back to the local summary without changing checkpoint or resume behavior.
